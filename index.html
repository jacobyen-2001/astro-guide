🪐 路線 A
📦
在 Server 安裝 Miniconda3 並建立 Virtual Env
一次設定，永久受益。讓每個專案有乾淨獨立的 Python 環境。
1
SSH 進入 Server
打開 Mac 的 Terminal（Command+Space 搜尋 Terminal），連線到老師的伺服器。
Terminal — zsh
❯ ssh username@server.address # 輸入密碼後，你就進入 server 了 username@server:~$ _
💡 username 和 server.address 換成老師給你的帳號和 IP/hostname。
2
下載並安裝 Miniconda3
Miniconda 是輕量版的 Anaconda，只帶 conda 本身，其他套件自己裝，乾淨很多。以下指令在 Server 上執行。
bash — server
# 下載 Miniconda3 安裝腳本（Linux x86_64，server 通常是這個）
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh

# 執行安裝
bash Miniconda3-latest-Linux-x86_64.sh

# 安裝過程中按 Enter 確認、輸入 yes 接受 license，
# 最後問要不要 auto-activate → 建議輸入 yes
⚠️ 安裝完後需要重新開啟 terminal（或執行 source ~/.bashrc）才會生效。此時 prompt 前面會出現 (base)。
3
建立 Virtual Environment（虛擬環境）
為每個研究專案建立獨立環境，套件版本不會互相衝突。以天文分析為例，建立一個叫 astro 的環境。
bash — server
# 建立環境，指定 Python 版本（建議 3.11）
conda create -n astro python=3.11

# 啟動環境（prompt 會從 base 變成 astro）
conda activate astro

# 確認 Python 路徑正確
which python
# → /home/username/miniconda3/envs/astro/bin/python ✓
虛擬環境架構
miniconda3/
主目錄
envs/
astro/
← 你的天文環境
project2/
← 另一個專案，互不干擾
4
安裝常用天文套件
確認 (astro) 環境已啟動後，安裝以下套件。
numpy
數值計算基礎
scipy
科學計算、統計
matplotlib
畫圖標配
astropy
天文專用工具庫
pandas
表格資料處理
jupyterlab
互動式 notebook
bash — server (astro env)
# 一次裝完所有常用套件
pip install numpy scipy matplotlib astropy pandas jupyterlab

# 如果需要 FITS 檔案處理
pip install astropy-healpix

# 驗證安裝成功
python -c "import astropy; print(astropy.__version__)"
# → 6.1.0 （或類似版本號）✓
5
啟動 Jupyter Lab，並設定 Port Forwarding
Jupyter 跑在 server 上，但我們要在 Mac 的瀏覽器裡看到它。這需要兩個步驟。
Port Forwarding 原理
🖥️
Mac
localhost:8888
SSH Tunnel
Port 8888
🗄️
Server
localhost:8888

你在 Mac 瀏覽器開 localhost:8888，流量透過 SSH 隧道轉到 server 的 Jupyter

步驟 5a：在 server 上啟動 Jupyter（不開瀏覽器）
bash — server
jupyter lab --no-browser --port=8888

# 會看到一串輸出，包含 token URL，先不用管，複製 token 備用：
# http://localhost:8888/lab?token=abc123xyz...
步驟 5b：在 Mac 本機另開一個 Terminal，建立 SSH tunnel
Terminal — Mac 本機
# -N 不執行指令、-L 建立 port forwarding
ssh -N -L 8888:localhost:8888 username@server.address

# 這個 terminal 掛著就好，不會有輸出
🚀 現在打開 Mac 的 Safari 或 Chrome，輸入 http://localhost:8888，貼上剛才的 token，就能看到 Jupyter Lab 了！
6
進階：寫一個啟動腳本，以後一行搞定
在 server 上建立 start_jupyter.sh，以後只需一個指令。
~/start_jupyter.sh
#!/bin/bash
conda activate astro
jupyter lab --no-browser --port=8888
讓腳本可執行
chmod +x ~/start_jupyter.sh
# 之後只需執行：
./start_jupyter.sh
🛸 路線 B
⚡
VSCode Remote SSH — 在本機操作遠端 Server
透過設定 SSH config file，VSCode 可以像操作本地資料夾一樣操作 server，還有完整的 IntelliSense 和 debugger。
1
在 Mac 安裝 VSCode
去 code.visualstudio.com 下載 Mac 版本，安裝完後把 VSCode 加入系統 PATH。
VSCode 內部 — Command Palette
# 在 VSCode 中按下 Cmd+Shift+P 開啟 Command Palette
# 輸入：Shell Command: Install 'code' command in PATH
# 按 Enter 執行

# 驗證：在 Terminal 輸入
code --version
# → 1.89.x 類似版本號 ✓
2
安裝 Remote - SSH 擴充套件
這是 Microsoft 官方出的擴充，讓 VSCode 可以直接連到遠端 server。
📦 在 VSCode 左側點擊 Extensions 圖示（四個方塊），搜尋 Remote - SSH，選 Microsoft 出品的版本安裝。

同時也安裝 Python 和 Pylance 擴充套件，讓 Python 開發體驗更好。
3
設定 SSH Config File
建立 ~/.ssh/config 檔案，之後連線只需選擇 host 名稱，不用每次輸入 IP 和帳號。
Terminal — Mac 本機
# 如果 ~/.ssh/ 目錄不存在，先建立
mkdir -p ~/.ssh
chmod 700 ~/.ssh

# 用 nano 或 vim 編輯（nano 對初學者友善）
nano ~/.ssh/config
在檔案中加入以下內容：
~/.ssh/config
# 老師的 server（自訂一個你好記的名字）
Host        astro-server
    HostName    your.server.ip
    User        your_username
    Port        22
    ServerAliveInterval 60
    ServerAliveCountMax 3

# 如果有第二台 server 也可以繼續加
# Host second-server
#     HostName 192.168.x.x
#     User another_user
📋 nano 的儲存方式：Ctrl+O → Enter（確認）→ Ctrl+X（離開）
🔐 ServerAliveInterval 60 和 ServerAliveCountMax 3 可以防止連線閒置太久自動斷掉，天文分析跑很久的時候很重要。
4
設定 SSH Key（免密碼登入，強烈推薦）
以後連線不用每次輸入密碼，而且更安全。
Terminal — Mac 本機
# 在 Mac 本機產生 SSH 金鑰對（一路按 Enter 用預設值即可）
ssh-keygen -t ed25519 -C "your_email@example.com"

# 把公鑰複製到 server（會要求輸入一次密碼）
ssh-copy-id astro-server

# 之後測試是否不需密碼就能連入
ssh astro-server
# → 直接進入 server，不需密碼 ✓
SSH Key 運作原理
Mac
私鑰（id_ed25519）
保存在本機
🤝
Server
公鑰（authorized_keys）
放在 server
💡 如果 ssh-copy-id 不存在，可以改用：
cat ~/.ssh/id_ed25519.pub | ssh astro-server "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
5
在 VSCode 連接 Server
設定好 config 後，連線只需幾個點擊。
🖱️
  1. 左下角點擊 >< （藍色的遠端連線圖示）
  2. 選擇「Connect to Host...」
  3. 選擇你剛才設定的 astro-server
  4. VSCode 會開啟新視窗，左下角變成 SSH: astro-server 即成功
  5. 點擊 Open Folder，瀏覽 server 上的目錄
6
在 VSCode 選擇 Conda 虛擬環境
告訴 VSCode 要用哪個 Python interpreter（也就是你在路線 A 建立的 astro 環境）。
VSCode Command Palette
# Cmd+Shift+P → 輸入：Python: Select Interpreter
# 選擇帶有 (astro) 字樣的那個：
~/miniconda3/envs/astro/bin/python

# 之後右下角 status bar 會顯示：
⎇ Python 3.11.x ('astro': conda)
✅ 完成！現在你可以直接在 VSCode 裡打開 server 上的 .py 檔案，有自動補全、語法檢查、debugger，還可以在 VSCode 的 Terminal 執行，完全不需要來回複製貼上。
7
加碼：在 VSCode 裡直接跑 Jupyter Notebook
路線 B 也可以用 Jupyter，不需要另外開瀏覽器，全部在 VSCode 裡搞定。
📓 安裝 Jupyter 擴充套件（VSCode 搜尋 Jupyter，Microsoft 出品），然後：
  • 在 VSCode Explorer 右鍵 → New File → 取名為 analysis.ipynb
  • 右上角 Select Kernel → 選 astro 環境
  • 直接在 VSCode 裡寫 notebook，輸出圖表也會內嵌顯示

日常工作流速查表
上手之後每天最常用的指令
bash — server 常用指令
# 啟動 astro 環境
conda activate astro

# 查看目前有哪些環境
conda env list

# 安裝新套件
pip install package_name

# 匯出目前環境所有套件（方便備份或給別人）
pip freeze > requirements.txt

# 從 requirements.txt 重建環境
pip install -r requirements.txt

# 離開虛擬環境（回到 base）
conda deactivate
Terminal — Mac 本機（SSH Tunnel 啟動 Jupyter）
# 一行搞定 port forwarding（-f 背景執行）
ssh -N -f -L 8888:localhost:8888 astro-server

# 之後直接在瀏覽器打開
http://localhost:8888
